# 🌮 Casa Mexico

**Authentic Mexican Cuisine**

A vibrant Mexican restaurant website showcasing the flexible BAAM Studio restaurant template system.

## 🎨 Theme

- **Primary**: Orange (#EA580C) - Vibrant & Bold
- **Secondary**: Green (#16A34A) - Fresh
- **Accent**: Yellow (#FBBF24) - Festive
- **Style**: Colorful, festive, energetic

## 🚀 Quick Start

```bash
npm install
npm run dev
# Visit http://localhost:3002
```

## 🌶️ Features

- 60+ Mexican dishes with spice level indicators
- Margarita & cocktail menu
- Festive geometric patterns
- Photo gallery
- Online ordering
- Bilingual support (English/Spanish)

**Part of the BAAM Studio multi-cuisine restaurant template system.**
